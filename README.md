# Fake Economy

Client-side Fabric 1.21.11 mod for changing the money and shard values shown on a sidebar scoreboard.

## Features
- GUI opened with a customizable keybind in Options > Controls.
- Fake Money and Fake Shards fields.
- Local payment simulator that subtracts arbitrary amounts from fake money.
- Supports plain numbers and K/M/B/T/Qa/Qi/Sx/Sp/Oc/No/Dc suffixes.
- No client commands.
- No fake transaction is sent to the server.
- Settings are saved in `config/fake-economy.json`.

Default keybind: Right Alt.
